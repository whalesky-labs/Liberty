# Liberty v2.0.0-alpha.3

版本范围日期：2026-11-26（Asia/Shanghai）。本页维护 alpha.3 的变化和交付边界；公开状态、发行提交与 Release ID 以 [GitHub Release](https://github.com/whalesky-labs/Liberty/releases/tag/v2.0.0-alpha.3) 和随包清单为准。完整双语条目见 [CHANGELOG](../../CHANGELOG.md#200-alpha3---2026-11-26)，前版范围见 [alpha.2](2.0.0-alpha.2.md)。

## 中文

第三个 2.0 alpha 增加模块菜单折叠，调整设置数字输入、运行时状态和进度，以及商店与打工地图的卡片对齐。收起菜单保留页面、草稿与键盘操作，并释放内容区域。

修复历史字幕和 Word 慢速导出的锁范围、默认 AI 模型选择、模型保存失败误报成功、整任务删除时取消摘要，以及成长配饰卸下后被刷新重新装备的问题。人员导入在应用入口集中业务校验，农场与打工纯规则归入领域层，旧逐字稿按结果快照复用显示投影。

本版没有新增数据库迁移，沿用 alpha.2 的 schema v12、默认运行时和独立候选资料目录。仍为未签名、未公证的原生候选归档，不切换稳定生产入口。真实 GUI、IME/无障碍、跨设备 ASR 和完整安装升级回退仍需独立验收。安全扫描依据当前例外策略，既有生产 Python 运行时例外仍在 2026-11-30 到期，没有延期或宣称零漏洞；要求见[发布门槛](../architecture/release-readiness.md)。

## English

The third 2.0 alpha adds collapsible module navigation and refines Settings number inputs, runtime status and progress, and card alignment in the Pet Store and work maps. Collapsing the menu preserves the page, drafts and keyboard interaction while reclaiming content space.

Fixes cover lock scope during slow subtitle and Word exports, explicit default AI model selection, failed model saves reporting success, summary cancellation on whole-job deletion, and refresh restoring unequipped growth accessories. Member-import business checks now run at the application boundary, pure farm/work rules live in the domain layer, and legacy transcript projections are reused per result snapshot.

This version adds no database migration and retains alpha.2's schema v12, default runtime and isolated candidate profile. Archives remain unsigned and unnotarized, and the stable production entry is unchanged. Real GUI, IME/accessibility, cross-device ASR and full installation upgrade/rollback acceptance remain separate requirements. Security scans use the current exception policy; existing production Python runtime exceptions still expire on November 30, 2026, without extensions or a zero-vulnerability claim.
