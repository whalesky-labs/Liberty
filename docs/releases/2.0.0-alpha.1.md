# Liberty v2.0.0-alpha.1

状态：发布准备中。日期：2026-11-24（Asia/Shanghai）。本页描述本次 alpha 的产品范围和发布要求，不表示已创建标签或已公开发行。

## 中文

这是 Liberty Go + MyGo 原生客户端的首个 2.0 alpha。它包含本地会议任务、逐字稿与说话人结果、AI 总结、会议纪要和 DOCX/Markdown/TXT 导出，以及模型、模板、人员管理、桌宠和本地打工玩法。完整变更见 [CHANGELOG](../../CHANGELOG.md#200-alpha1---2026-11-24)。

支持 macOS Apple Silicon、macOS Intel 和 Windows x64。计划提供三个未签名 `.tar.gz` 候选归档，macOS 归档内为 `.app`，Windows 为便携目录；应用名称保留 `Liberty Native Candidate`。本次 alpha 不提供已签名、公证或完成升级事务验收的 DMG/MSI。

启动后使用独立的 `com.westng.liberty.native-candidate` 资料目录，不自动接管稳定版资料。测试请使用合成或已备份的隔离资料；同一资料目录不要同时启动多个客户端。退出应用后可以移除候选应用，稳定版资料不会因此被清理。显式资料导入、备份与恢复按[原生模块说明](../../apps/native/README.md)操作。

首次本地转写需要联网下载 Python、ffmpeg 与模型。本地音视频转写使用本地运行时；AI 总结按用户选择调用配置的远端服务，密钥保存在系统凭据存储。远端兼容目前支持既有任务查询，不提供新上传协议。

已知限制：完整 GUI、输入法/读屏及跨设备体验仍需验收；本地 ASR 的真实新安装与处理证据主要来自 macOS ARM，三平台 CI 不等于每台目标设备上的 ASR 质量或性能验收。未完成签名、公证、安装升级/回退与生产观察。运行时安全扫描继续采用既有 Torch 例外，到期日为 2026-11-30；发布前须重新扫描，过期不能自动延长。详见[发布要求](../architecture/release-readiness.md)。

## English

This is the first 2.0 alpha of Liberty's Go + MyGo native client. It includes local meeting jobs, transcripts and speaker results, AI summaries, meeting notes, DOCX/Markdown/TXT exports, resource and member management, desktop companions and local work-game features.

Targets are Apple Silicon Macs, Intel Macs and Windows x64. The planned assets are three unsigned `.tar.gz` candidate archives containing a macOS `.app` or a portable Windows directory. The application retains the name `Liberty Native Candidate`. Signed/notarized DMG/MSI installers and completed installation-upgrade acceptance are outside this alpha's deliverables.

The app uses the separate `com.westng.liberty.native-candidate` profile and does not automatically take over the stable profile. Use synthetic or backed-up isolated data and one writer per profile. See the [Native guide](../../apps/native/README.md) for explicit imports, backups and restore. Initial local transcription requires downloading Python, ffmpeg and models. AI requests use the configured remote provider; secrets remain in the system credential store. Remote compatibility supports existing-job queries, without a new upload protocol.

Full GUI, IME/accessibility and device acceptance remain incomplete. Actual fresh ASR installation and processing evidence primarily covers macOS ARM; three-platform CI does not establish ASR quality/performance on every device. Signing, notarization, installer upgrade/rollback and production observation remain pending. Existing Torch security exceptions expire on 2026-11-30 and must not be silently extended. A new security scan is required before publication.

## 资产与发布核验 / Assets and publication checks

| 平台 / Target | 候选归档 / Candidate archive |
| --- | --- |
| macOS Apple Silicon | `liberty-native-candidate-2.0.0-alpha.1-darwin-aarch64.tar.gz` |
| macOS Intel | `liberty-native-candidate-2.0.0-alpha.1-darwin-x64.tar.gz` |
| Windows x64 | `liberty-native-candidate-2.0.0-alpha.1-windows-x64.tar.gz` |

三个归档必须来自同一确切提交，经共同完整门禁、目标主机解包执行 `--version` 和独立资产校验。每个平台的 candidate/build manifest、SHA-256、Native SBOM 和许可证清单随准备结果提供；它们不能标记 `productionReady:true`、已签名或已公证。

公开发布时必须核对 `v2.0.0-alpha.1` 指向的确切提交、Release ID、`prerelease:true`、`make_latest:false`、预期资产和下载后的摘要；稳定版 latest 继续指向既有稳定发行。准备阶段不触发旧 Tauri 发布链，不用旧端安装包填充原生 alpha 资产。
