# Liberty v2.0.0-alpha.2

版本范围日期：2026-11-26（Asia/Shanghai）。本页描述 alpha.2 源码与交付边界；是否已公开、发行提交及 Release ID 以 [GitHub Release](https://github.com/whalesky-labs/Liberty/releases/tag/v2.0.0-alpha.2) 和随包清单为准。历史版本见 [alpha.1](2.0.0-alpha.1.md)。

## 中文

这是 Go + MyGo 原生客户端的第二个 2.0 alpha，主要新增麦克风中英文实时转写与自动双向离线翻译、会话历史、定稿编辑、失败补译及双语 SRT/VTT/TXT 导出。识别和翻译在本机执行，无需翻译服务 API Key；首次使用需要下载受校验的运行时和模型。音频不落盘，定稿及译文保存在本地 SQLite。操作与当前限制见[实时翻译](../live-translation.md)。

原生界面更新模块导航、系统配色、窗口材质和设置布局，并修复语言切换后的子窗口标题及标准关闭菜单。队列分页、结果缓存、后台轮询、图片缓存和虚拟商店列表减少重复读取与重绘；标题栏显示实际进程树 CPU 和平台内存口径。

仓库新增 15 组可编辑 3D 伙伴动作和 macOS Metal 原生预览，属于开发预览；本次发行客户端仍使用原桌宠。不能将素材生成、姿态校验或预览渲染通过视为正式桌宠替换、Windows 渲染或长期性能验收。

交付继续采用三个未签名 `.tar.gz` 候选归档，应用名称为 `Liberty Native Candidate`，使用独立的 `com.westng.liberty.native-candidate` 资料目录。macOS 归档包含 `.app`，Windows 为便携目录；不提供已签名、公证或完成安装升级验收的 DMG/MSI，未切换稳定版生产入口。

数据库从 v10 经顺序迁移升级到 v12，保存实时会话、字幕和自动翻译方向。升级前保留备份；旧二进制不能直接写入新版数据库，回退须恢复升级前快照或使用保留的旧资料目录。同一资料目录只能由一个客户端写入。资料迁移和恢复见[原生模块说明](../../apps/native/README.md)。

默认运行时仍为 FunASR `1.3.9+liberty.local2`；`1.4.29+liberty.local1` 是需要显式准备和选择的 `funasr-upgrade` 隔离候选，不随默认发行切换。完整 GUI、无障碍、跨设备麦克风、识别/翻译质量和生产观察仍有未完成项。模型可能误译数字、币种、人名及术语，定稿应人工检查。现有 Torch 例外到期日仍为 2026-11-30，发布需重新扫描，不自动延期。

## English

The second 2.0 alpha of the Go + MyGo native client adds live Chinese/English microphone transcription, automatic offline translation in both directions, session history, caption editing, translation retries and bilingual SRT/VTT/TXT exports. Recognition and translation run locally without translation-service API keys. Initial setup downloads verified runtimes and models. Audio is not saved; finalized text and translations are stored in local SQLite.

Native navigation, system colors, window materials and Settings layouts are updated, with localized child-window titles and the standard Close Window menu action. Paged queues, result caching, background polling, image budgets and virtualized store rows reduce repeated reads and rendering. Toolbar usage reflects the actual process tree and platform-specific memory measurements.

Fifteen editable 3D companion actions and a macOS Metal preview are included as development tooling. Shipped clients retain the existing companion. Asset validation and preview rendering do not establish production integration, Windows rendering or long-running performance acceptance.

Delivery remains three unsigned `.tar.gz` candidate archives, containing a macOS `.app` or portable Windows directory. The app retains `Liberty Native Candidate` and its isolated `com.westng.liberty.native-candidate` profile. Signed/notarized DMG/MSI installers and completed upgrade acceptance are outside this alpha; the stable production entry is unchanged.

Sequential migrations advance SQLite from v10 to v12. Keep a pre-upgrade backup: older binaries cannot write the upgraded database, and rollback requires an earlier snapshot or retained old profile. Use one writer per profile. The default runtime remains FunASR `1.3.9+liberty.local2`; `1.4.29+liberty.local1` remains an explicitly prepared, isolated upgrade candidate.

Full GUI/accessibility, microphone behavior across devices, speech/translation quality and production observation remain incomplete. Review names, numbers, currencies and terminology manually. Existing Torch exceptions still expire on 2026-11-30; publication requires a fresh scan and does not extend them. See the [release requirements](../architecture/release-readiness.md) and [changelog](../../CHANGELOG.md#200-alpha2---2026-11-26).

Publication binds one exact commit in main history to all three host-built candidates and thirteen verified assets. The Actions bot verifies the tag, source, Release ID, public downloads and hashes, publishes a prerelease, and preserves the stable latest release. CI and binary-format checks do not replace the outstanding device and product acceptance described above.
