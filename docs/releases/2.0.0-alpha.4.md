# Liberty v2.0.0-alpha.4

准备日期：2026-11-28（Asia/Shanghai）。状态：发行准备，尚未公开。本文定义第四个 Native 预发行版的范围、升级边界与预期交付；提交、CI、候选构建、标签和 Release 的实际状态分别核验。完整双语更新条目见 [CHANGELOG](../../CHANGELOG.md#200-alpha4---2026-11-28)，下载以 [GitHub Releases](https://github.com/whalesky-labs/Liberty/releases) 的实际资产为准。

## 中文

第四个 2.0 alpha 补齐批量导入、句子回听与倍速、正文及讲话人校对、独立人工纪要和来源定位。人工稿用于默认导出，AI 历史保留，新增 AI 整理由用户主动发起。设置、导航、更新检查和宠物福利页面同步改进，Windows 标题栏及应用图标修复一并纳入。

本版计划首次通过现有安装器链交付 macOS DMG 与 Windows 当前用户 MSI，同时保留便携候选归档。macOS 为 ad-hoc 临时签名，未作 Developer ID 签名或公证；Windows 无可信发布者签名。安装包沿用独立候选资料目录，不切换稳定生产入口，也不包含完整 Python、ffmpeg、依赖与模型；首次本地使用仍需联网下载。

数据库从 alpha.3 的 schema v12 升至 v13，增加人工纪要及来源关联。升级遵循顺序迁移、备份与失败恢复；退出旧版后再启动新版，不同时打开同一资料目录。回退 alpha.3 或更早二进制必须使用兼容的升级前快照，不能直接写入 v13 资料。详见[资料与恢复](../../apps/native/README.md#生产资料接管与离线恢复)及[会议工作流](../meeting-workflow.md)。

系统声音与麦克风混音适配已进入源码，但权限拒绝/恢复、设备切换和长时间录音仍需目标设备验收；GUI、输入法、读屏、Intel/Windows 托管 ASR、普通内存设备预算和安装升级/回退尚未全部闭合。3D 伙伴继续为开发预览。现有 Python/Torch 安全例外于 2026-11-30 到期；候选构建和公开发行都必须重新通过当时有效的扫描策略，不延期、不宣称零漏洞。

## English

The fourth 2.0 alpha adds batch import, bounded segment playback and speed control, transcript/speaker corrections, independent manual minutes and source navigation. Saved manual notes feed default exports, AI history is retained, and further AI work remains user initiated. It also updates Settings, navigation, update checks and companion benefit pages, including Windows title-bar and application-icon fixes.

This version intends to deliver community macOS DMGs and Windows per-user MSIs through the existing installer pipeline, alongside portable candidate archives. macOS uses ad-hoc signing without Developer ID or notarization; Windows has no trusted publisher signature. The isolated candidate profile remains, with no stable production cutover. Installers do not bundle the full Python/ffmpeg/runtime/model setup; initial local use still needs downloads.

Schema v13 adds manual notes and source associations to alpha.3's v12 database. Sequential migration, backup and recovery rules remain. Quit the older app first and do not open one writable profile from two clients. Older binaries require a compatible pre-upgrade snapshot for rollback and must not write the upgraded v13 database.

System-audio and mixed-input adapters are implemented, but permissions, device changes and long recordings still need device acceptance. GUI, IME, screen readers, Intel/Windows managed ASR, ordinary-memory budgets and installation upgrade/rollback remain incomplete. The 3D companion remains a development preview. Current Python/Torch exceptions expire on November 30, 2026; both candidate building and publication must pass fresh scans under valid policy, without extending exceptions or claiming zero vulnerabilities.

## 发布前核验 / Pre-publication verification

- 同步六处版本来源并运行原生 presentation 生成器；检查 `v2.0.0-alpha.4` 与源码、双语 changelog 一致。
- 对确切提交执行完整质量、安全、兼容、race 和三平台检查；先前版本或 PR 的通过记录不能替代新候选验证。
- 通过 `build-native.yml` 为全部三平台构建，核验归档与安装器内程序、来源、架构、版本、文件清单及 SHA-256。
- 公开发行前按 [CI/CD](../architecture/ci-cd.md#native-bot-发布事务)使用成功候选 run；发行源码须属于 main 历史。由受控发布工作流创建标签与 Release，核对 Release ID、标签提交、19 资产及无需登录的下载，保持 `prerelease:true`、`make_latest:false`。

These are separate gates. A version edit or successful compile does not establish publication or production readiness.
