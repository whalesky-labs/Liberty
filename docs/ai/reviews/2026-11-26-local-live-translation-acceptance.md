## 已完成实现

- 用户明确要求无需配置第三方服务或 API Key。实时链路改为 FunASR 流式识别 + CTranslate2/Argos 本地中文→英文翻译；在线翻译传输、模型选择与术语表入口已移除。总结功能独立保留。
- 首次下载由 Liberty 管理，归档和展开文件逐项校验 SHA-256；额外代码、目录、符号链接和内容变化被拒绝；每次启动前重新核对内置脚本。使用独立 Python `-I -B` 进程，会话内复用，结束/超时/取消回收进程树。
- 协议校验精确字段、类型、重复键、序号、UTF-8 和大小上限；过长输入和输出截断明确失败。识别和翻译无需网络请求，模型下载与推理分离。
- 麦克风采集、暂停/恢复、刷尾句、会话历史、编辑、补译和 SRT/VTT/TXT 导出已实现；schema v11 共享迁移、原文事务、revision 约束和启动恢复已覆盖。运行环境缺失时仍加载已有历史，不把麦克风可用性当作历史数据的前置条件。
- 收尾复核修复识别输入队列短暂满时过早触发积压保护的问题：在原有容量内等待并继续消费识别事件，真正耗尽容量仍明确停止；旧实现三次均触发新增回归失败，修复后相关 race 通过。还修复删除会话后旧字幕仍显示、新会话被旧轮询覆盖的问题；本地模型身份从 manifest 获取，避免应用层另写版本常量。
- OpenMP 在音频间隙使用 `OMP_WAIT_POLICY=PASSIVE` 与 `KMP_BLOCKTIME=0`，减少推理线程忙等。只影响实时进程，文件转写 Runner 不变。行为依据 [LLVM OpenMP 说明](https://openmp.llvm.org/design/Runtimes.html)。

## 短测性能

硬件为 Apple M1、16 GiB。固定公开流式样例补 1 秒静音并循环，实际服务、识别、翻译和采集子进程按墙钟运行 60 秒；不是尽快跑完文件的吞吐测试。CPU 以单核 100%，内存取 macOS physical footprint。以下短测的采样窗口从首段译文完成后开始，不包含整个冷启动峰值。

| 指标 | 调整前 | passive 等待对照 |
| --- | ---: | ---: |
| CPU 中位数 | 124.37% | 75.31% |
| CPU P95 | 138.02% | 90.52% |
| 采样窗口内存中位数 | 1868.70 MiB | 1863.92 MiB |
| 语音结束至原文定稿 P95 | 0.422 秒 | 0.921 秒 |
| 定稿翻译耗时 P95 | 113 ms | 104 ms |
| 完成并保存的片段 | 10 | 10 |
| 停止后测试进程内存 | 16.77 MiB | 17.02 MiB |

这两次短测显示等待策略减少 CPU，但也有延迟取舍，不能外推为所有设备固定节省比例。GUI 实际麦克风生命周期观察中，标题栏约 1787 MiB 在结束后回落至约 121 MiB，相关采集/识别子进程消失；此次麦克风没有用于语义准确率评估。服务回放指标不含独立 GUI 进程，不能把两种口径混为一谈。

此前另一版 ASR-only 两小时尝试在约 25.7 分钟因输入落后退出，未通过；它与完整检查/编译同时运行，也没有排除系统休眠影响。第二次完整服务回放运行 2751.47 秒（约 45.9 分钟）后触发 `live_audio_backpressure`，同样未通过两小时验收；停止前最后内存采样约 1494.8 MiB、无翻译积压，该时段有最终构建运行。复核发现上述过早拒绝的队列问题并修复；不能把这项代码缺陷直接当作第二次失败的唯一根因。重新执行时等待构建结束，同时涵盖离线翻译、持久化、导出和退出回收，通过进程作用域的 `caffeinate -i` 防止空闲休眠，不改系统永久设置。

这支持“本机重复公开样例的两小时稳定性通过”，不证明无任何内存泄漏、所有负载下不卡顿或识别/翻译准确率达标。先前失败保留为诊断证据；修复与取消并行构建同时改变，因此不能定量归因于单个因素。

## 翻译质量与剩余边界

长回放除标准句外还出现短促“嗯”的额外识别片段，片段总数不是正确句数；此测试的非空译文检查只用于持久化/稳定性。12 个手工构造的短句实际译文覆盖会议时间、否定、日期、百分比、技术术语和离线使用，单段约 53–139 ms。发现 `总价是二百五十元，不是二千五百元。` 被译为美元金额；显式写“人民币”的另一个样例正确。公开语音样例中的“达摩院”也被译为 “Dharma House”，专名需人工校正。该结果表明需要会议领域人工评审，不能声称数字、币种或专有名词可靠。没有用脆弱规则自动改写币种，也没有把有非空译文当作质量通过。

FunASR 1.4.29 仍是显式隔离候选，默认生产仍 1.3.9+liberty.local2。切换需要现有 CER/WER/DER 和平台门槛。Windows 真机按用户要求暂缓；Intel、8 GiB 和更广麦克风/权限/设备移除场景未验证。系统声音、英语输入、悬浮字幕、译文朗读不在本次首版实现中。
