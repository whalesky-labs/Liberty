## 分类与必填信息

每份文档开头声明：

```text

状态：草案 / 待确认 / 已确认 / 执行中 / 已完成
创建日期：YYYY-MM-DD
最后核实：YYYY-MM-DD
适用范围：模块、平台、版本或用户流程
权威边界：能证明什么，不能替代什么
依据：代码、测试、契约、正式文档或外部来源
```

引用路径、完成度、测试结果、平台状态或外部版本前重新核实；无法核实的内容标明缺少的证据。整理日期不替换原测试日期。
