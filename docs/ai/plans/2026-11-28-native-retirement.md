## 顺序与边界

1. 验证 Native 从共享输入独立生成、检查和历史数据回放；修复实际发现的旧端依赖，不以移除检查代替修复。
2. 对待晋级的确切候选收集目标设备 GUI/IME/读屏、真实 ASR/翻译、录音权限与设备恢复、首次安装及升级回退证据。源码编译、自动测试与候选发行分别记录。
3. 全部门槛关闭后，在同一退役变更中切换启动通道/资料身份、bundle identity、输入清单与生产发布入口，并删除旧 GUI、Tauri 命令/capabilities、旧构建链和专属依赖。保留历史 SQL 迁移、共享输入、冻结兼容样本、许可证和 NOTICE。
4. 在最终切换提交上重跑启动、迁移、锁、恢复与回退冒烟；提交、推送和公开发布仍需对应授权。

## 本轮修复

- 主展示生成器原先只导入动画生成脚本，其 CLI 入口条件使生成和检查均未执行。现改为调用显式生成函数，增加缺失/过期动画与压缩差异回归。
- Native 策略校验原先要求旧端 workflow 存在。现将 Native 受控工作流校验与临时旧端入口校验分开；根 `ci:check` 和完整交付门禁继续检查旧端及完整质量要求。
- 增加 `pnpm native:source:check`，从仓库外的临时副本重建九组共享生成产物，核对输入摘要，再执行 Native 完整检查、冻结兼容与三目标编译。失败阻断、源路径和生成物完整性有相邻回归；操作边界见[开发指南](../../development.md)。

- 固定工具链可用；本机初始 `native:check` 通过。
- 真实系统凭据验收通过：隔离条目写读、替换、删除、轮换、SQLite 恢复、快照引用保留与最终回收。
- 固定 OSV 2.5.0 / cargo-deny 0.20.2 执行的 `security:check` 与 `licenses:check` 通过当前政策。三个生产运行时均保留完整的过滤和未过滤扫描；未过滤扫描仍有已知漏洞，当前例外保持 2026-11-30 到期，没有延期或删除规则。
- 系统声音合成采集测试因 ScreenCaptureKit 权限未授予而跳过；没有开始采集，不能记为真实录音通过。
- 隔离验收的首轮在 ASR 阻断自测失败，原因是复制清单漏带 `benchmarks/asr` 配置；已补齐，最终完整复跑通过。
- 完整 `pnpm check` 通过，包含 Native、共享 Python、旧端前端与 Rust、Clippy、发布和 CI 策略；`go test -race -count=1 -timeout=30m ./...` 全包通过。外置卷硬链接回退和旧端 Web 分块提示仍存在。
- 仓库外的最终隔离副本通过九组生成内容核对、`native:verify`、`native:compat` 和三目标主程序/测试包编译及二进制格式核验；输入摘要和工作区修改标记保存在本地忽略目录，本次是未提交工作区证据，不是发行归因。早期仓库内副本的检查已停止，以避免 Node 向上解析依赖影响独立性证明；该次停止不记为通过。
- 复用当前清单绑定的隔离运行时，真实无 Key 转写复跑通过（80.80 秒）：禁用/启用说话人两种模式、校对保存、TXT/Markdown 导出、SQLite 重开及奖励恰好一次，未创建 AI 总结。测试进程及子进程内存为启动前 16.2 MiB、峰值 6365.5 MiB、关闭后 18.7 MiB；不含 GUI，不能据此确认 8 GiB 使用体验。本次复用已有运行时，不是全新下载安装或多场景质量证据，也未确定历史超时的根因。
- CI 策略 78 项通过；最终隔离/工作流边界回归 50 项通过，文档链接、围栏与 `git diff --check` 通过。本轮未提交、推送、打包、公开发布或删除旧客户端。

## 提交后的跨平台复核

上述记录是提交前的工作区验收。后续 [PR #53](https://github.com/whalesky-labs/Liberty/pull/53) 的 Linux CI 在动画重建时发现小数尾数漂移；生成器改为按原生绘制器的 float32 精度序列化帧内数值，仍对完整 JSON、SVG 路径和元数据严格比较，并重新生成嵌入资源。后续检查与隔离复跑结果以该 PR 的最终提交及本地输入摘要为准，不覆盖上面的历史结果。
