- `pnpm native:compat` 全部通过：v0–v10 冻结库迁移、写入、恢复、文件和导出回放。v12→v13 碰撞回滚、重试与重复启动另有专项测试。
- `pnpm native:build:matrix` 三目标编译与格式校验通过；开发过程曾遇到工作区其他未完成编辑或本轮编辑期间快照不一致的失败，最终实际输出优先，不等同实机验收。
- Rust workspace：292 通过、18 按原条件忽略；Clippy warnings-as-errors 命令通过（外置卷增量缓存硬链接退化为复制的工具链提示仍存在）。前端 49 项通过，类型检查与 Web 构建通过；Python lint 与 135 项通过；原生发布/安全基线、现行发布策略、CI 策略 77 项通过。安全基线不等于漏洞扫描。

- 无 Key 固定公开样本首次真实验收：两种说话人模式转写、校对保存、TXT/Markdown、重开通过，未生成 AI 纪要，320.39 秒；测试进程树启动前约 16.0 MiB、停止后约 18.9 MiB，不含 GUI，未采完整峰值。

## P2 评估与未闭合事项

默认会议问答目前缺少能同时满足免费、无需额外部署和普通配置资源预算的已验证方案；不因竞品提供就强制接入付费 API 或常驻本地 LLM。当前先提供关键词检索、人工来源关联和回听，后续评估需要明确高频问题样本、回答来源正确率与资源预算。

日历、文件夹监听、CLI/MCP 暂缓：目前没有已验证用户频次与权限/运维收益证据；批量导入先减少重复操作。桌宠沿用显式开关及现有生命周期，本轮没有留存实验，不能判断其收益。

剩余：系统录音授权后的真实采集、权限拒绝/恢复、设备切换与长时间稳定性；Windows/Intel 与 8 GiB 设备；首次下载安装/升级/回退；固定中英混说、数字/人名/术语与多人噪声标注集、质量和延迟测量。没有用户真实媒体、目标设备与权限证据时，不制造验收通过记录。
